This diagram teaches the step-by-step sequence of a Domain Name System (DNS) lookup. It shows the communication flow between a client and four types of DNS servers when resolving a domain name to an IP address. The numbered steps illustrate the request-and-response process: first, the client sends a query to a recursive resolver; second, the recursive resolver asks the root DNS server; third, the root server directs the query to the Top-Level Domain (TLD) DNS server; fourth, the TLD server directs the query to the authoritative DNS server; and fifth, the final IP address answer is returned back through the resolver to the client.
